# The frozen entry order of `struct cpl_api`, the function table of the CPL C API (spec/cabi.md 4.1, 4.2,
# Appendix A.1; spec/toolchain.md 1.12, 12, T78).
#
# Format: one entry per line, `<version> <member>`, in the order of the members after `struct_size` and
# `api_version`, entry i (0-based) at byte offset 8 + 8 * i on an LP64 target; `<version>` is the version
# `<major>.<minor>` of the C API that added the entry. Lines that are empty or start with `#` are comments.
#
# The table is append-only within a major version: an entry is never reordered or removed, and a new entry is
# appended with the minor version that adds it, which must then be CPL_API_VERSION_MINOR of cpl.h. Every entry of
# C API 0.1 is present in every library of major version 0. crates/cpl-rt/tests/headers.rs checks this file against
# cpl.h; spec/cabi.md 4.1 names the test that also guards the rule on later edits.
